@AGENTS.md

Capsule Memory is a lightweight utility for securely storing and synchronizing existing agent memories and skills across machines and harnesses. Agents choose what to remember and use; the shared archive stores encrypted history, with plaintext, keys, and search kept device-local.

Use the shared rules above. The project agent adapters in `.claude/agents/` point to canonical personas in `.agents/personas/`; `.claude/skills` points to the canonical skills. Load only the persona and skills needed for the authorized task.
